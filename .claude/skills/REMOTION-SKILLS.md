# Skills de Remotion

Copiadas de https://github.com/remotion-dev/skills (commit 6c67adcd9cdbe6eb84d76342da89b225f9161cb2, 22-oct-2026).
Son las skills oficiales de Remotion para agentes: `remotion-best-practices` engloba a las demás.

El proyecto de vídeo de Remotion NO vive en este repo (la web es pública y la sirve GitHub Pages):
está en `03_redes/remotion/` del disco HD2026.

Remotion es gratis para particulares y equipos de hasta 3 personas, también con uso comercial:
https://www.remotion.dev/docs/license/faq

Para actualizar: `npx skills add remotion-dev/skills` o volver a copiar la carpeta `skills/` de ese repo.
